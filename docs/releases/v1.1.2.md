# POM2 v1.1.2

**Fixed: "POM2 is damaged" on macOS.** An accented file name in the package
broke the app's signature when the Finder copied it into *Applications*. macOS
then called the app damaged and offered no way to allow it from System Settings.

The emulator itself is unchanged from
[v1.1.0](https://github.com/habib256/pom2/releases/tag/v1.1.0), which has the
full list of new features. v1.1.1 was tagged but never published.

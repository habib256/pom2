# POM2 v1.2.0

> [!WARNING]
> **First launch on macOS or Windows: you have to allow POM2 once.** The packages
> are not notarized by Apple or signed for Windows, so both systems block a
> downloaded copy.
>
> **🍏 macOS: "Apple could not verify POM2".** Drag **POM2** from the `.dmg` into
> *Applications* and try to open it. Click **Done**, then open the Apple menu →
> **System Settings** → **Privacy & Security**, scroll down to **Security**, click
> **Open Anyway** and confirm.
>
> A package older than v1.1.2 says *"POM2 is damaged"* instead and has no
> **Open Anyway**. Do not move it to the Trash. Run this in Terminal:
>
> ```bash
> xattr -dr com.apple.quarantine /Applications/POM2.app
> ```
>
> **🪟 Windows: "Windows protected your PC".** Click **More info**, then
> **Run anyway**.

- **Porte Parole:** speech synthesis now uses Sébastien Pourcel's MEA8000 engine.
- **DIX calibration:** improved PAL raster synchronization on //e and //c.
  DIGIDREAM SID runs on //c; pausing preserves the picture. Thanks to
  **Grouik, fenarinarsa and French Touch** for the sources and timing references.
- **Reliability:** safer disk writes, correct MAX boot timing, safer browser
  speech snapshots, insertion sounds tied to media changes, and quieter IWM diagnostics.
- **Browser:** A2FileCmd downloads on demand; startup shrinks from **50.3 to
  18.3 MiB**. Choose **File > Boot A2FileCmd**.
- **Network:** built-in NAT supports Uthernet on desktops without libslirp,
  including Windows.
- **Input:** keyboard joystick, second controller, improved paddles and Sirius Joyport.
- **Disk tools:** create DOS 3.3/ProDOS disks, bootable binary disks and repaired WOZ copies.

Also: per-monitor CRT settings, recorded ImageWriter II sounds, contextual PNG
screenshots, text copying, firmware recovery, SDK hard disks and a compatibility corpus.

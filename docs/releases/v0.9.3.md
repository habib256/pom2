# POM2 v0.9.3

- Fixed disk writes lost when write-protecting a modified floppy, a locked 3.5" disk missing from ProDOS, and hard-disk images now save in the background.
- Liron card boots hard disks with up to fourteen units; SmartPort cards start with eight; the ProDOS HD card has a second drive.
- Apple //c: native mouse firmware, Mockingboard 4c support, and Slot Configuration shows its real ports.
- Mockingboard, Phasor and speech fixes: correct SSI263 wiring, sample-accurate register writes, no audio-thread allocations.
- No more window freezes when switching profiles or applying slot changes with FujiNet or telnet active; Windows can save write-protected images again.
- One test now covers every media write path; bug hunts #18 to #21 closed.

# POM2 v0.8.2

- Added ARM64 desktop, Pi400 and WASM downloads, bringing the release to seven packages.
- Added mouse capture: click the screen to grab; `Ctrl+Alt+G` or middle-click releases it.
- Unified package contents and added payload checks and boot tests before publication.
- Improved disk-save durability, SmartPort handling, snapshots and media ejection.
- Fixed DLGR editor memory overruns and issues in FujiNet and printer handling.
- Updated the browser demo to Total Replay v6.1 and added stale-build detection.

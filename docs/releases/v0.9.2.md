# POM2 v0.9.2

- Fixed lost disk writes when enabling write protection, plus Disk II, SmartPort and 3.5" media handling.
- Added eight-unit SmartPort support and easier volume mounting, ejection and write protection.
- Corrected CPU bus cycles, peripheral timing, speech playback and printer audio.
- Fixed double lo-res alignment, CRT scaling, paint tools and cassette WAV loading.
- Improved rewind, telnet input and Workstation Card emulation; blocked additional guest routes to host loopback.
- Removed 55 MB of development files from packages and strengthened regression tests.

# POM2 v0.8.3

- Fixed parallel graphics printing, including colour output from The New Print Shop.
- Added read-only mounting of 3.5" WOZ images.
- Fixed sprite-export buffer overruns, printer margins, ProDOS filename collisions and Echo+ snapshot restoration.
- Fixed the browser crash on F10 and added a fullscreen toolbar button.
- Floppy Emu image selection now boots the disk; its SD card has a Disk Library tab.
- Expanded memory-safety, concurrency and malformed-input testing.

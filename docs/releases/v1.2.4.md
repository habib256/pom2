# POM2 v1.2.4

> [!WARNING]
> **First launch on macOS or Windows: you have to allow POM2 once.** The packages
> are not notarized by Apple or signed for Windows, so both systems block a
> downloaded copy.
>
> **🍏 macOS: "Apple could not verify POM2".** Drag **POM2** from the `.dmg` into
> *Applications* and try to open it. Click **Done**, then open the Apple menu →
> **System Settings** → **Privacy & Security**, scroll down to **Security**, click
> **Open Anyway** and confirm.
>
> A package older than v1.1.2 says *"POM2 is damaged"* instead and has no
> **Open Anyway**. Do not move it to the Trash. Run this in Terminal:
>
> ```bash
> xattr -dr com.apple.quarantine /Applications/POM2.app
> ```
>
> **🪟 Windows: "Windows protected your PC".** Click **More info**, then
> **Run anyway**.


- **A disk in the wrong drive.** Dropping a 5.25-inch image on a 3.5-inch
  drive (or the other way round) was refused with the reason. POM2 now also
  offers the empty drive of this machine that takes that disk, as a button
  — the drive the machine is waiting on, even while it spins empty at boot.
  Nothing is redirected without you.
- **The //c Plus's real clock is shown.** Whenever an accelerator sets the
  machine's clock, the toolbar shows it beside the speed menu: 4.09 MHz, or
  1.02 MHz after Esc held at reset. "1×" is the pacing, not the clock; its
  tooltip says how to switch.
- **Less audio crackle on a Raspberry Pi.** The emulation thread, which
  makes the sound, asks the system for more priority itself, as far as the
  user may: once a nice of -10 is allowed for your user in
  `/etc/security/limits.conf` (POM2's log says how), no more renicing POM2 by
  hand. A nice you set yourself is kept. Never real time.
- **Faster tape winding** (#21). A held REW or FF speeds up as a real deck's
  reels do, from 30× to 240× in about three seconds.
- **A hard disk is never patched into a file another program replaced.**
  If a sync tool or a disk editor rewrites a mounted `.hdv` / `.2mg` while it
  runs, POM2 no longer writes the guest's blocks into that foreign volume
  (which cross-linked it): the guest's disk goes to a copy beside the image
  (`<name>.guest-…`), whole, as a floppy's already does, and the log says so.
- **Better bug reports.** Help ▸ Report a bug opens a GitHub issue that
  already holds the version, the edition (browser demo or desktop, and its
  OS) and the machine. On Linux the link also goes to the clipboard.
- **POM2 in RetroArch, v1.2.4.** The libretro core released with this
  version ([POM2 Libretro v1.2.4](https://github.com/habib256/pom2/releases/tag/libretro-v1.2.4))
  names its disk saves so a frontend can find them, maps keys onto the
  RetroPad for 39 games, allows netplay and run-ahead in
  RetroArch, opens Android's shared-storage content, and its Windows build
  no longer needs the Visual C++ runtime.
- **Reviewed before release.** Five rounds of review over everything since
  v1.2.3 fixed 144 defects
  ([the list](https://github.com/habib256/pom2/blob/v1.2.4/docs/audits/bug-hunt-2026-11-25.md)).

Full list in the [changelog](https://github.com/habib256/pom2/blob/v1.2.4/CHANGELOG.md).

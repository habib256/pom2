# POM2 v0.7

- First tagged release, with Linux x86_64 tarball and Debian packages.
- Added desktop integration and disk-image file associations.
- Fixed installation packaging and included the full Grappler+ firmware.
- Added automated CPU, display and boot tests, plus WASM build verification.

Requires `libglfw3`, an OpenGL driver and your own Apple ROM dumps; see the bundled `roms/README.txt`. Windows and macOS packages and the native //c+ 3.5" boot path are not yet available.

# POM2 v0.9.0

- Added Le Chat Mauve variants, the Apple II Workstation Card, TransWarp, 4play and Echo+.
- Added the Apple //e Unenhanced PAL profile.
- Implemented firmware-driven SmartPort and 3.5" boot paths for Liron, //c and //c+.
- Browser settings and media now survive reloads.
- Added printer models, ProDOS host-folder volumes, TNFS media mounting and the `pom2_core` SDK.
- Improved CRT rendering and fixed VIA timing affecting DIX and OLDSKOOL.

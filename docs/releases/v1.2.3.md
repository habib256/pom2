# POM2 v1.2.3

> [!WARNING]
> **First launch on macOS or Windows: you have to allow POM2 once.** The packages
> are not notarized by Apple or signed for Windows, so both systems block a
> downloaded copy.
>
> **🍏 macOS: "Apple could not verify POM2".** Drag **POM2** from the `.dmg` into
> *Applications* and try to open it. Click **Done**, then open the Apple menu →
> **System Settings** → **Privacy & Security**, scroll down to **Security**, click
> **Open Anyway** and confirm.
>
> A package older than v1.1.2 says *"POM2 is damaged"* instead and has no
> **Open Anyway**. Do not move it to the Trash. Run this in Terminal:
>
> ```bash
> xattr -dr com.apple.quarantine /Applications/POM2.app
> ```
>
> **🪟 Windows: "Windows protected your PC".** Click **More info**, then
> **Run anyway**.


- **POM2 in RetroArch.** The libretro core is released with this version
  ([POM2 Libretro v1.2.3](https://github.com/habib256/pom2/releases/tag/libretro-v1.2.3)):
  every Apple II from the ][ to the //c Plus, NTSC or PAL, floppies, 3.5"
  disks and hard disks, Mockingboard, Phasor, AppleMouse, Le Chat Mauve,
  save states and rewind, M3U playlists, a RetroPad keyboard, and the
  desktop's CRT glass as RetroArch shader presets RetroArch loads by itself.
  Netplay is checked frame by frame: two machines given the same inputs
  keep the same state byte for byte, a rollback replays exactly, and a
  player who joins stays in step — keyboard games included (Port 3:
  "Keyboard (for netplay)").
- **More disks open as they are.** ShrinkIt archives (`.shk`, `.sdk`,
  `.bxy`), DiskCopy 4.2 images (`.dc`, `.dc42`) and Applesauce flux captures
  (`.a2r`, versions 2 and 3) mount like any image, in a local copy: the
  original is never written. A zip or archive holding several disks (a
  game's sides) mounts the first, and the drive offers the others.
- **Protected disks.** POM2 was run against MAME and AppleWin on the whole
  of 4am's woz-a-day collection: of 2245 titles, POM2 boots 99.3 % to a
  picture, MAME 98.7 %, AppleWin 98.2 %
  ([the audit](https://github.com/habib256/pom2/blob/main/docs/audits/woz-a-day-2026-11-24.md)).
  POM2 now boots every title either of the others boots. The run found and
  fixed: an empty drive's data register that never stood still, so 4am's
  Anti-M loader waited forever for a disk instead of asking for one; weak
  bits drawn so that SSI's RDOS check (Battalion Commander, Bomb Alley,
  Carrier Force) could never pass, and placed where the WOZ reference puts
  them (Decimal and Percent Word Problems); Mr. Do's declared bit timing;
  Glutton's nibble count, now that the platter's speed drifts between
  revolutions, and that drift jumping mid-revolution (13 more titles boot).
- **13-sector disks with no Apple ROM.** POM2 now has its own 13-sector
  Disk II boot PROM, as it has its own 16-sector one: DOS 3.1 and 3.2 disks
  (VisiCalc 1.37, Apple Bowl, the Programma catalogue) boot with no Apple
  firmware. Apple's PROMs, when present, always win.
- **The bundled games** follow the current pom2games builds.

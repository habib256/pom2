# POM2 v0.9.6

- **Monochrome graphics:** orange and blue retain their native light/dark
  dot patterns instead of becoming solid gray areas; green and amber
  phosphor persistence follows the same 560-dot signal.
- **Alt+Enter** switches between fullscreen with the mouse captured and
  fullscreen with the mouse free, including from focused controls.
  Keyboard releases survive focus changes, preventing stuck game keys.
- **Drive sounds:** automatic mode uses MAME for classic Disk II drives
  and Virtual II for the //c-family 5.25-inch mechanism. Import your local
  recordings in Audio Mixer; missing recordings fall back to MAME.
  Manual bank selection remains available.
- **Bundled disks:** A2FC XL v0.9.6 (6502 edition), DIX-fix, ChromaBreak 1.0
  and Micro-Sokoban 1.2, with source links and SHA-256 checksums.
- **Drives and display:** a dedicated vertical drive stack and an optional
  Monitor II frame; the 3.5-inch manual eject hole sits below the slot; mapped gamepads drive all four analog paddles.
- **Disk II timing:** spindle stop occurs at the exact cycle deadline,
  including when a CPU advancement batch crosses it.
- **SmartPort:** malformed FORMAT/INIT parameter lists now return the
  firmware error codes instead of reporting success.
- Corrected the keyboard image's right arrow and improved nightly
  sanitizer alerts with failed jobs and useful error excerpts.

Virtual II recordings remain user-supplied. Protected-disk gameplay checks
are evidence for the tested images, not a claim of universal compatibility.

# POM2 v0.9.6

![Default desktop: Ultima V on Apple //c PAL, Monitor II frame, machine keyboard and right-column drive tabs](https://raw.githubusercontent.com/habib256/pom2/v0.9.6/pic/POM2-default-desktop.png)

- **New desktop:** Monitor II-framed screen above the machine keyboard,
  with Drives, Disk Library and Slot Configuration tabbed on the right.
  Insert disks by clicking drive artwork or dropping images onto it.
- **Machine keyboards:** //c, //c PAL and //c+ select their own keyboard
  skin and hotspots, with the same displayed proportions as the IIe.
- **Boot and profiles:** drive controls select the mounted controller,
  respect native firmware priorities and report conflicting boot targets.
  Profile changes validate the new ROM before replacing the machine;
  Liron configurations support HD mounting.
- **Display and input:** monochrome preserves native dot patterns;
  Alt+Enter toggles mouse capture in fullscreen. Focus changes no longer
  leave guest keys held, and gamepads support all four analog paddles.
- **Storage and sound:** corrected Disk II spindle timing and SmartPort
  FORMAT/INIT errors. Automatic drive sounds follow the machine family;
  Virtual II recordings can be imported locally, with MAME fallback.
- **Four bundled disks:** A2FC XL v0.9.6 (6502 edition), DIX-fix,
  ChromaBreak 1.0 and Micro-Sokoban 1.2, with SHA-256 checksums.

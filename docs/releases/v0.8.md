# POM2 v0.8

- Added Linux AppImage, macOS Universal 2, Windows and Raspberry Pi packages.
- Added dockable panels, display scaling, a command palette and fullscreen switching.
- Added Microsoft SoftCard CP/M support, paint and sprite editors, Ethernet cards and FujiNet relay.
- Expanded printer emulation with colour output, PDF export and print history.
- Improved performance, stereo audio and disk saving.

Limitations: Uthernet I has no Windows host transport; Uthernet II inbound connections are unsupported. Native //c-class 3.5" boot and browser persistence are not yet implemented.

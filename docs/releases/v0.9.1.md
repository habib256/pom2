# POM2 v0.9.1

**The bug-hunt release: ten rounds of adversarial hunters over four days,
every defect confirmed by a probe, fixed, and pinned by a test that fails
without the fix. And one policy change a real machine already had: a disk in
a drive writes.**

69 commits since v0.9.0. No new hardware; what was there is truer, safer with
your files, and honest about what it does.

## Highlights

- **Media write by default.** Every 5.25", 3.5", HDV, CFFA and SmartPort image
  comes up writable — DOS `SAVE`, ProDOS saves and a game's high scores land in
  the file on eject and on quit. Every media panel and the Slot Config media
  rows show a **Write-protected** tick with a WRITABLE / WRITE-PROTECTED
  status beside it; a WOZ/2IMG write-protect flag or a read-only file still
  wins. The ProDOS host folder sync stays an opt-in. Users who had explicitly
  ticked write-back off keep their setting.

- **POM2 can format a disk.** With the shipped P6 ROM, DOS 3.3's `INIT`
  answered `I/O ERROR` on every image: the revolution anchor a burst is
  reduced against was set once at motor-on, and a non-WOZ track's period moves
  with every sync run written — sector 0's data field landed on its own
  address field. Only `INIT` writes a whole track, which is why no boot or
  `SAVE` test had seen it.

- **The //c+ boots a 3.5" it is allowed to write.** The Sony drive's /READY
  line waited for the spindle; the //c+ firmware strobes MotorOff and then
  polls /READY — every 3.5" boot that ever worked went through the ROM's
  write-protected branch, so ticking write-back was exactly what stopped it.

- **The 6502 and the MMU.** NMOS indexed stores and page-crossing loads now
  issue their un-fixed-address dummy read (`STA $C030,X` clicks the speaker
  twice, as the silicon does); a `$C3xx` write under INTCXROM latches INTC8ROM
  like the read; the undocumented opcodes cost what the silicon charges; the
  full Tom Harte corpus passes.

- **The 6522, four fixes.** The T1 read-back was one cycle low (DIX rasters
  crawled); an ACR write in the two cycles before an underflow threw the
  interrupt 65536 cycles out; a batched `advance(n)` ending on an underflow
  swallowed a period and inverted PB7; the Mockingboard's lazy sync read the
  counter one too high and crashed OLDSKOOL.

- **The picture.** Text was painted white on the green and amber phosphors;
  a-z was folded onto A-Z over the II/II+ character ROM; the mixed text band
  was painted from the frame's end state instead of per beam segment; a
  zero-persistence phosphor froze an erased dot on a paused machine; the Le
  Chat Mauve's latch ring is stamped with the clock the video events use.

- **The rewind ring.** A media write landing *during* a scrub is now caught at
  the seek; re-enabling Record starts an empty timeline instead of splicing
  two; every reset drops the latched debugger stop so a breakpoint on the entry
  fires; the TransWarp's `$F000` shadow is reconciled on restore instead of
  destroying Applesoft.

- **Your files.** Every write path commits through a temporary name unique per
  process and per call (the snapshot writer was the last one); the print
  history reopens a 57" tractor form; two POM2 instances cannot publish each
  other's snapshot; the SCC refuses a short blob instead of reading past it;
  the SmartPort bus refuses a header it cannot carry.

- **The guest inside the perimeter.** The Uthernet II's loopback fence held
  against every alias tried; a per-datagram UDP error no longer destroys the
  socket; telnet BINARY turns back off; the `--ai-control=` and `--fujinet=`
  ports refuse garbage and overflow instead of binding somewhere else.

## Also in this release

- The AI control server: `POST /mem` writes the bank it names, `\uXXXX` is
  decoded, `/eject` on an empty bay is a 400 instead of a cleared rewind ring.
- The mouse that jumped past the pointer in A2 File Cmd holds still: a
  closed-loop correction is pushed only once the previous one is drained.
- Profiles: the CPU mode is set before the slot rebuild (a //e → ][+ switch
  gave the CFFA the 65C02 firmware on an NMOS core); the //c+ hands its
  devices the 4× clock; a plugged TransWarp hands its 3.5× to the speaker
  and the tape; File > Reload ROM slices a //c dump the //c way.
- The printers: `ESC p`, `ESC !`, the 32-stop tab rack, A-8 and AutoFeed no
  longer stacking, the DMP eating `ESC g`'s body, the ImageWriter II decoded
  from its manual rather than from a port.
- The importer keeps a 4:3 photo at 4:3 on GR and DHGR; the sprite editor's
  PNG export stays inside its buffer.
- A Grappler+ or ThunderClock with no expansion EPROM no longer claims the
  `$C800` window it cannot serve.
- The nightly sanitizer schedule no longer cancels the push run it shares a
  ref with.

## Notes

- No package is signed: macOS is ad-hoc signed (right-click → Open on first
  launch), Windows is unsigned (SmartScreen → More info → Run anyway).
- Packages carry the ROM set and the UI assets, never a disk library. Bring
  your own images.
- `POM2_MEDIA_WRITE_DEFAULT=protected` makes every medium come up protected
  for a process (a kiosk, a shared master set); the test suite runs that way.

# POM2 v0.9.1

- Disk images are writable by default; explicit protection and existing write-back preferences are preserved. Host-folder sync remains opt-in.
- Fixed DOS disk formatting and writable 3.5" boot on the //c+.
- Corrected 6502 bus cycles, memory paging and VIA timing, including DIX and OLDSKOOL issues.
- Fixed display colours, rewind restoration, CPU worker recovery and mouse tracking.
- Improved file saving, printer emulation, image import, sprite export and network handling.
- Expanded regression coverage and isolated tests from user media and settings.

Set `POM2_MEDIA_WRITE_DEFAULT=protected` to start all media write-protected.

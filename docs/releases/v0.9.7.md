# POM2 v0.9.7

- **More 3.5-inch media:** mount 800K GCR `.moof` disks with their original
  track timing and bit cells. On an enhanced Apple IIe, the new `superdrive`
  slot card provides a ProDOS block interface for 400K/800K GCR and 1.44 MB
  MFM images. The 1.44 MB path does not emulate the SWIM chip directly.
- **Resumable sessions:** save and reopen supported II/II+/IIe machines with
  read-only Disk II media, including protected WOZ/FLUX images, and supported
  card state. Sessions require matching ROMs and configuration; unsupported or
  writable media are refused. Use File → Save session / Open session on desktop.
- **More hardware:** VidHD Super Hi-Res, Slinky memory, S.A.M. DAC, Zip Chip,
  SNES MAX controllers and CFFA3000 SmartPort support. Phasor speech and
  Uthernet I/II behavior have also been expanded and corrected.
- **FujiNet CONFIG boot:** the panel can start FujiNet-PC and boot its CONFIG
  disk. The official runtime is bundled for macOS, Windows x64 and Linux x64;
  Linux ARM can still use a physical FujiNet board.
- **Everyday fixes:** the browser opens on an Apple //c with DIX-fix, full
  screen follows the window's monitor, and disk writes and exports have
  additional corruption safeguards. The default speaker/Mockingboard balance
  is closer to MAME's Apple II signal model.
- **Bundled disks:** A2 File Cmd XL is updated to v0.9.8; DIX-fix,
  ChromaBreak 1.0 and Micro-Sokoban 1.2 remain available. The Micro-Sokoban
  image matches its published v1.2 checksum.

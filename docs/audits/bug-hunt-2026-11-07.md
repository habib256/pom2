# Bug hunt — 2026-11-07 (two waves, twelve domains)

Twelve read-only reviewers, one domain each, in two waves. Wave 1: the fresh
code (uncommitted diff + the two commits merged on 2026-11-06), the sound
path, the media write paths, the memory system, the host-facing surfaces
(AI server, NAT, NICs), saved state (snapshots, sessions, rewind). Wave 2: the
6502 core, video, the media read paths, input, threading and machine
lifecycle, printing and serial. Every finding below was re-read in the code
before it was acted on; a fix is pinned by a test that fails without it,
unless the line says otherwise.

## Deferred, with what it needs

- **Rewind inside a Disk II write burst** (data loss, rare): `DiskImage::writeFraming` is not in the rewind media snapshot, so a resumed burst re-frames mid-nibble. Needs a `D2S1` v5 tail; sessions parse that blob at fixed offsets, so it wants its own change and test.
- **3.5" eject phase 3 identifies the medium by path** (a narrow race with a same-file remount): compare `mountId()` as the StorageCoordinator paths do.
- **IWM accesses stamped at the instruction start** (//c+, Liron): pass `accessCycle()`, keeping `tick()` monotonic against the frame tick.
- **Opcode fetch / operand / stack stamps** off by 1-3 cycles in the bus watch (data accesses are right): hot path, measure with `pom2_bench`.
- **An empty SmartPort bay** answers "no device" on the //e path and "drive, no disk" on the //c bus path: one meaning for both.
- **Quarter-tracks 157-159** loaded but unreachable (clamp 156; MAME 164): [F], no mechanical-stop figure found.
- **AN2 font bank** read live at paint time, not per frame: a `VideoEventKind::An2` and the segment state.
- **AI `/mouse`** keeps its own 8-bit counter, out of step with the GUI's; `reset` injects motion.
- **`Core::setMouse`** latches for the session after a push that cannot move the cursor.
- **AN3 after reset**: Memory has AN3 low with DHGR off (a pair no switch produces); Le Chat Mauve assumes high. [F]: a meter on a //e.
- **Mockingboard comments** still say the AY replay runs on the CPU clock (it runs on the bus clock): reword before someone "fixes" SND-1 back.
- **Alt on a ][ / ][+ presses PB0/PB1**: those machines have no Apple keys — intent to confirm.
- **`AudioMix` / speaker / DAC** allocate on the audio thread at a buffer-rung change.

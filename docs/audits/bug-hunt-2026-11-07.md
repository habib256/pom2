# Bug hunt — 2026-11-07 (three waves, eighteen domains)

Twelve read-only reviewers, one domain each, in two waves. Wave 1: the fresh
code (uncommitted diff + the two commits merged on 2026-11-06), the sound
path, the media write paths, the memory system, the host-facing surfaces
(AI server, NAT, NICs), saved state (snapshots, sessions, rewind). Wave 2: the
6502 core, video, the media read paths, input, threading and machine
lifecycle, printing and serial. Every finding below was re-read in the code
before it was acted on; a fix is pinned by a test that fails without it,
unless the line says otherwise.

## Deferred, with what it needs

- **AN3 after reset** — settled at grade C: every //e and //c RESET handler
  throws `$C05F` within a few instructions (enhanced //e `$C2B0`, unenhanced
  `$C234`, //c and //c+ `$FA75`), so a ROM reset ends with AN3 high, as Le
  Chat Mauve assumes. The pre-firmware pair (AN3 low, DHGR off) is
  invisible; what the IOU latch does at the RESET edge itself still wants a
  meter on a //e ([F]), and no software can see it.

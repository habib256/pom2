# Bug hunt — 2026-11-19 (before v1.2.2)

Two independent reviewers over everything added on 2026-11-19 (the developer
tooling batch e874c621, the `.2mg` support, the corrected ][+ ROM): one on
the headless / capture / trace code, one on the GUI / WASM / CLI code. They
changed nothing and built nothing; each finding below was checked against
the code before it was fixed, and the ones marked *measured* were re-run.

## Fixed

| # | Finding | Fix | Pinned / checked by |
|---|---|---|---|
| 1 | `pom2_headless --wav` under `--pal` or `--speed N`: the WAV clock was read before the first frame, from the NTSC budget — PAL 50 frames gave 52 435 samples (44 029 due), `--speed 2` twice too many. *Measured.* | The clock the speaker is given: the standard's × the speed. | Re-run: 44 032 / 44 063 / 36 720 samples for PAL / x2 / NTSC (≈ 44 029 / 44 060 / 36 716). |

Also corrected: the docs said a `--mount` / link mount is "not persisted".
The mount writes nothing, but every mounted disk — the positional one
included, as it always was — is remembered at quit by
`persistRebuildSettings`.

## Not fixed, and why

- **A `?url=` link with "Resume this machine" on** is still replaced by the
  resume, as before today: the C++ cannot tell it from the default DIX boot.
  The new keys and `?embed=1` are protected (#6). Settling it needs the page
  to say "this is a link" (a flag), a CLI change of its own.
- **Copy link and the //c+'s on-board 3.5" drives** (slot −1): not listed,
  not counted as skipped. Minor; a drive-key scheme for them does not exist
  in Apple2TS's naming either.
- **`--load` reads at most 64 KiB + 1** of a file, so an AppleSingle with a
  large resource fork or comment is refused as truncated. A program cannot
  exceed RAM below `$C000` anyway; the limit is on the wrapper.
- **`TP_ASSERT`'s message joins any partial log line pending**: documented
  behaviour of the port (the pending line IS the message).
- **`--cycles`'s last slice** hands the speaker a scaled clock for that
  slice (a skewed `--wav` tail): it predates today's change.

A2osX-0.95-STABLE.800.po — A2osX 0.95, Stable Release Build No. 2642

What it is
  A2osX, a multitasking operating environment for the enhanced Apple //e,
  //c and IIgs (65C02 and 128 KB required), running on ProDOS. Kept here as
  a test disk: its drivers reach hardware POM2 emulates and little else
  exercises — Uthernet I/II, the SSC (polled and interrupt-driven), the mouse,
  Mockingboard, Grappler/Grappler+/Parallel Interface, RamWorks, the No-Slot
  Clock — all under an interrupt-driven multitasking kernel.

Using it
  It writes to its own disk (logs, configuration): boot a COPY so this file
  stays pristine, or tick "Write-protected" on it first. An 800K .po goes to
  the slot-5 SmartPort 3.5" on the default //e map; any //e enhanced, //c or
  //c+ profile. With no password file it logs in as root.
